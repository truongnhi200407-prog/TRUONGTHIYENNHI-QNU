# BÁO CÁO NĂNG LỰC SỐ CÁ NHÂN

## 1. Giới thiệu
Repository này được tạo nhằm lưu trữ các tài liệu phục vụ học tập và thực hiện bài tập đánh giá năng lực số cá nhân.

## 2. Nội dung
- Báo cáo đánh giá năng lực số cá nhân.
- Bảng so sánh các nền tảng trí tuệ nhân tạo (AI).
- Tài liệu tham khảo phục vụ học tập và nghiên cứu.

## 3. Mục đích
Hệ thống hóa tài liệu học tập, nâng cao kỹ năng sử dụng công nghệ số và ứng dụng AI hiệu quả trong học tập.

## 4. Tác giả
Sinh viên thực hiện bài tập.
